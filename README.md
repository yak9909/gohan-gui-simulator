# CTRPF UI Preview

New Nintendo 3DSの上下画面を実解像度で再現し、CTRPluginFramework v0.8.0向けの自前チートメニュー、キーボード、リスト、通知を操作できるプレビューです。

## 起動

Windowsでは `start.bat` をダブルクリックします。`index.html` を直接開いても動作します。Node.jsが利用できる環境では、次のコマンドでも起動できます。

```sh
npm start
```

ブラウザで <http://127.0.0.1:4173> を開いてください。外部ライブラリやインターネット接続は不要です。

## 表示仕様

- 上画面400×240 px、下画面320×240 pxをブラウザのピクセルへ1:1で表示
- 描画・入力更新は30 FPS固定
- 美咲ゴシック第2の公式BDFから8 px・1bitビットマップを直接抽出
- 数値項目・数値入力・スライダー値・HEXの `0x` と `A`～`F` だけPixelMplus10由来の8 px・1bitビットマップを使用
- 項目名や説明文など通常テキスト中の数字は美咲ゴシック第2のまま描画
- 通知は上画面右下、画面外右からCubic Ease Outで登場
- 通知背景は上画面が透けて見える半透明表示
- 退場時も画面右外へCubic Ease Out
- 連続通知時は既存通知を上へEase Outし、新着通知を最下段へ追加
- 複数の通知要求が同時に発生してもキューで40msずつ開始時刻をずらし、同時刻に複数の通知を登場させない
- 「通知を追加」「3件を連続追加」、またはSpaceキーで発火
- ピクセル等倍と、上下画面をそれぞれ縦横ぴったり2倍にする表示切替。表示幅が足りない場合は縦横比を維持して画面内へ収め、横スクロールバーを出さない
- TOP／BOTTOMのカラーピッカーから上下画面の背景色を個別に変更可能

## 自前チートメニュー

- 上画面の左40%（160×240 px）にCubic Ease Outで登場・退場
- 選択背景は約1.8秒周期でほんのり明滅し、項目移動時はCubic Ease Outで追従
- 数値系ItemをDPad左右で変更すると、選択背景が入力方向へ跳ねて戻る
- DPadを200ms長押しすると60ms間隔で連続入力（項目移動は連続入力中のみ先頭・末尾で停止）
- ルート20項目・スクロールテストフォルダ24項目を収録し、10行表示で選択追従スクロール
- インライン・上画面・下画面のリストボックスは右側からイーズアウトで登場・退場し、DPadを200ms長押しすると連続移動（連続入力中のみ先頭・末尾で停止）。メニューを閉じるとインライン／下画面リストは未確定の選択をキャンセルして退場するが、上画面リストは開いたまま残り、メニュー開閉量に追従して右側⇔画面中央をスライドする
- 上画面・下画面のリストボックスは、内容の高さを含めて画面の縦中央へ配置。チートメニューが閉じている場合、上画面リストは横方向も中央へ配置
- 大量リストは30項目を収録し、インライン6行／上下画面8行の固定窓と比例スクロールバーで表示
- フォルダ、チェックボックス、アクション、連動型数値／リスト、トグル型アクション、インラインリスト、10進数・16進数・float値、スライダーItem
- 連動型は`S`＋水色と説明欄の`SYNC`表示で通常項目と区別。STARTの`SETTINGS`には選択中の連動型数値／リストを現在値へ固定する`VALUE LOCK`を表示し、変更不可状態では新規固定を禁止。トグル型アクションは通常アクションと同じ見た目にし、ON/OFF値で状態を示す
- 全チートItemのホットキー設定と無効化。無効Itemは灰色表示のままカーソル選択と説明確認は可能だが、値変更・決定・適用・ホットキー設定は不可。入力待ちウィンドウはタッチ可能な下画面へ表示し、Yを離した後のボタン入力を全ボタンが離された時点で重複なしの組み合わせとして確定
- STARTで`SETTINGS`を開閉し、その中の`FAVORITES`からお気に入り一覧を開く。Rで選択Itemを登録／解除する。お気に入り一覧は元Itemそのものを参照するため、ON/OFF・値・適用待ち・ホットキー状態が常に共有される
- Simulatorではお気に入りを`localStorage`へ保存し、再読み込み後も復元する。各Itemは階層パス由来の安定キーで識別する
- 選択Itemの説明とホットキーは、R操作なしでメニュー右側へ常時表示
- 変更されたItemは黄色で表示。X短押しで選択Itemだけを適用。X/L長押しは600msで全適用／全戻し確認へ進み、進捗2/5未満は灰色、2/5以上600ms未満で離した場合は単体操作も行わず長押しだけをキャンセル
- チェック項目の「項目ON/OFF」と「効果ON/OFF」を分離。ホットキーは項目の適用値を変えず、項目OFF中は発火しない
- `無敵モード`／`壁抜け`は効果状態のシミュレーションを持ち、束縛なしでON適用すると効果ON、束縛ありではアームのみ。OFF適用では必ず効果OFF
- ホットキー設定だけを変更・適用しても現在の効果状態は変えない
- 数値・スライダー・リストは編集後のX適用で反映し、メニュー外からホットキーで開いた入力UIは確定時に直接適用する
- アクションItemはAを押した時点で関数と対応UIを即時実行し、未適用状態にはしない
- AでItemを選ぶと、選択背景とItem内容が右へ小さく跳ねて80msで戻る
- L短押しで選択Itemだけを直近の適用済み値・ホットキーへ戻す。Lを600ms長押しすると進捗バー完了後に全項目を戻す確認ダイアログを表示
- 未適用の変更がある状態でメニューを閉じると、「適用」「キャンセル」だけの確認ダイアログを表示。キャンセル時は変更を維持したままメニューへ戻る
- 閉じる確認・全適用確認・全戻し確認は、登場と退場の両方にアニメーションを使用
- 連動型はメニューを開いた時にシミュレートされたゲーム値を編集値・適用値へ同期し、読取失敗時は選択不可。適用時に値を書き戻す
- トグル型アクションはON→適用で一度実行してOFFへ戻り、短時間だけ値欄に`OK`を表示。ホットキーからは確認後に実行
- チェック項目の`[X]`は括弧と別描画し、`X`だけ赤系色で表示

## 下画面UI

- 10進数／16進数で位置が変わらない共通レイアウトの数値キーボード
- 10進数時のA～F、16進数時の符号・小数点など、使用できないキーは暗色表示になり入力も無効
- 上限・下限・ステップ付きの横向き数値スライダー
- `1.bmp`準拠の五段かな配列／`2.bmp`準拠の数字・記号・Caps・Shift付きQWERTY配列
- UIテスト内の「小型文字キーボード」から、8px文字を縮小せずキーと間隔だけを詰めたコンパクト版を表示
- 通常版／小型版文字キーボードの登場・退場時に、下画面へ薄い黒背景をフェードイン／アウト
- 入力欄のタッチ位置へカーソルを移動し、その位置への挿入とカーソル直前の文字の消去に対応
- 文字キーボードの選択色はタッチしているキーだけに表示し、未タッチ時はハイライトしない
- 濁点・半濁点・小字キーは、カーソル直前の文字を変換できる場合だけ有効化。同じキーを再度押すと元のかなへ戻り、別の変種から押した場合は元のかなを基準に変換（`っ→づ`、`ぱ→ば`など）
- 右側のEnterは無効な改行キーとして表示し、下段の「とじる」の右に独立した「けってい」ボタンを配置
- QWERTYのCapsとShiftは排他的に動作し、空欄・「かな」・「カナ」キーは無効
- かな配列のカナキーでカタカナ入力へ切り替え
- 上画面・下画面の汎用リストボックス

「チートメニューを開く」ボタン、画面下の仮想3DSボタン、またはキーボードで操作できます。矢印キーがDPad、Z/EnterがA、X/EscがB、CがX、VがY、QがL、RがR（メニュー内ではお気に入り切替）、EがZL、TがZR、1がSELECT、2がSTART（メニュー内では設定画面の開閉）です。

## 注意

`top.bmp`は読み込まず、上下画面は選択した単色背景で描画します。チートメニュー関連のパネル・選択帯・リスト・キーボードキーなどの背景は半透明で重ねます。

上画面の液晶自体は800×240ドットですが、裸眼立体視では左右の目に横400ドットずつが割り当てられ、CTRPFの通常描画座標も400×240です。ビットマップの形を崩さないため、以前のmm指定による物理実寸表示は廃止し、CSS表示も400×240またはその整数2倍だけにしています。ブラウザのズームは100%で使用してください。

フォント原本は `font-source/misaki_gothic_2nd.bdf` です。公式BDFに収録された7170字から、このプレビューで使う361字をビット列のまま抽出します。アウトライン変換、フォールバック、表示時の補間は一切行いません。

PixelMplus10のTTFはアウトライン専用で埋め込みビットマップを持ちません。数値用字形はPixelMplus10の公式ビルド元 `font-source/pixel-mplus/mplus_j10r-iso-W5.bdf` から取得し、10pxセルの空白行だけを除いて8pxセルへ収めています。字形のピクセル自体は拡大縮小していません。

## フォントの再抽出

同梱した公式BDFからWeb用JSONとCTRPF用C++を再生成するには、次を実行します。追加のフォントライブラリは不要です。

```sh
python tools/extract_misaki_gothic_2nd_8.py
python tools/extract_pixel_mplus_10_numeric_8.py
```

実機側は `MisakiGothic2nd8` と `PixelMplus10Numeric8` の各ヘッダー／ソースを通して、同じ1bitグリフを1ドット単位で描画します。

美咲フォントは、改変の有無や商用・非商用を問わず利用・複製・再配布できるフリーソフトウェアです。原文は `font-source/misaki.txt` と公式配布ページを参照してください。

PixelMplus10と元のM+ BITMAP FONTSはM+ FONT LICENSEです。原文は `font-source/pixel-mplus/README.md` と `LICENSE_E` を参照してください。
