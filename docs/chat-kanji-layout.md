# 漢字変換プレビュー配置基準

下画面プレビューの320×240参照画像を実測し、漢字変換UIは次の座標へ合わせる。

- キーボード外周: X=1..318（Canvas領域 x=1, width=318）
- 元キーボードの丸い上端: Y=66..67
- 最初のキー内容: Y=68から
- 「消去」列: X=279..318（width=40）
- かな1文字キー: 24×22
- 既存入力欄: Y=23から。プレビュー側で新しい入力枠を作らない
- 変換行: Y=49..67。元の丸い上端を覆い、Y=67を共有境界としてキーボードの追加行に見せる
- 「クリア」: 「消去」と同じ右端列 X=279..318。候補表示はその分だけ短くする
- 左右ボタン: 24×22、X=271 / 295、Y=1。下端Y=23で既存入力欄に重ねない

文字はユーザー提供の `Garden_msg_size16.bcfnt` を使用する。SHA-256は `1e24ed83bdf652dde77ab9e0065914518f9997a2916b66ad764bfc5ae57aff78` で、既存プレビューが記録しているフォントと一致する。候補文字だけでなく「クリア」と `←` / `→` も同BCFNTから抽出したA4グリフで描画し、ブラウザフォントやGohan Menu用Misakiフォントへ置き換えない。

左右ボタンの外観・押下色はGohan Menuのキーボードキー表現に合わせる。既存ACNL入力欄そのものは再構築・再描画しない。
